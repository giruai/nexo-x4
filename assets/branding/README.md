# NEXO X4 brand artwork

The icon and in-app mark are original geometric artwork for this project: two overlapping chain links in bright blue and green on a deep navy field. The links suggest a connection between the PS4 and Xbox Cloud experience without reproducing either platform's official logo. `nexo-x4-icon.svg` is the editable 512 × 512 source; `icon0.png` is its RGBA export for the PS4 package.

The in-app Canvas implementation lives in `src/ui/psbox/vendor/ui/brand.cpp`. Its original renderer and surrounding UI were credited to RafaelNGP under GPL-3.0-or-later; those source notices and other existing developer credits remain in their respective files. The NEXO X4 artwork was created for this project. The project is an independent client and the artwork does not imply affiliation with Sony or Microsoft.
